## Project Overview

Grafana datasource plugin for Litmus Edge that enables real-time data streaming visualization via NATS. TypeScript/React frontend + Go backend.

## Code layout

- `pkg/edge/`: NATS and DeviceHub clients.
- `pkg/plugin/`: data source configuration, health, and stream handlers.
- `src/components/`: Grafana configuration and query editors.
- `litmus-grafana/`: standalone Grafana image, Marketplace manifest, and provisioning.

## Build & Development Commands

- **Full build:** `npm run build`
- **Frontend build:** `npm run build:frontend`
- **Backend build:** `npm run build:backend` (Linux amd64 only — do NOT use `mage buildAll`, it cross-compiles all platforms and is much slower)
- **Frontend dev (watch):** `npm run dev`
- **Run Grafana with plugin:** `npm run server` (or `npm run up` for detached)
- **Typecheck:** `npm run typecheck`
- **Lint:** `npm run lint` (fix: `npm run lint:fix`)
- **Unit tests:** `npm run test:ci`
- **Backend tests:** `mage test`
- **E2E tests:** `npm run e2e` (first run: `npm run e2e:install`)
- **Stop Grafana:** `npm run down`

## Important Codebase Rules

- **Never edit files in `.config/`** — this directory is auto-generated by Grafana Plugin Tools. Extend configs from root-level files instead (e.g., `tsconfig.json`, `eslint.config.mjs`, `.prettierrc.js`).
- The Go backend binary name is `gpx_edge` — must match the `executable` field in `src/plugin.json`.
- Frontend uses Grafana Live (WebSocket streaming), not HTTP requests.
- Use these names for Edge settings: `EDGE_URL`, `EDGE_CLIENT_ID`, `EDGE_CLIENT_SECRET`, `EDGE_API_TOKEN`, `EDGE_VERIFY_TLS`, `EDGE_ACCESS_ACCOUNT_TOKEN`, and `EDGE_DOCKER_GATEWAY_IP` for their defined meanings. `EDGE_API_TOKEN` is the Litmus Edge API token for DeviceHub topic discovery. `EDGE_ACCESS_ACCOUNT_TOKEN` is the broker credential.

## Environment Setup

- Node.js 22+ (see `.nvmrc`), Go version from `go.mod`, Mage, Docker with Compose v2
- Copy `.env.example` to `.env`. For inside Litmus Edge mode (image default), change `EDGE_DOCKER_GATEWAY_IP` if the gateway is not `10.30.50.1`. For external mode, set `EDGE_EXTERNAL=true`, `EDGE_URL`, and `EDGE_ACCESS_ACCOUNT_TOKEN`. Set `EDGE_NATS_PROXY_PORT` if the broker does not use `4222`. Set `EDGE_API_TOKEN` to enable topic discovery in either mode.

## Release

1. Bump `package.json` and `package-lock.json` with `npm version X.Y.Z --no-git-tag-version`. Update `CHANGELOG.md` and the release pins in `litmus-grafana/mp.json`, `solution.json` (description), `README.md`, `litmus-grafana/README.md`, and `docs/litmus-grafana-quickstart.mdx`. Keep prior download entries.
2. Prepare the signed `litmus-edge-datasource-X.Y.Z.zip`, check install and removal on amd64 and arm64, and add the ZIP to Central and Contentful `downloads[X.Y.Z]` before the version becomes latest.
3. Push `vX.Y.Z` from the merged release commit. `.github/workflows/release.yml` builds, signs, and packages the plugin, pushes versioned and `latest` images, and updates the version in Contentful. Publish the install docs only after the matching signed ZIP and image are available. Verify the live entry's download, docs link, and tested Litmus Edge versions.
